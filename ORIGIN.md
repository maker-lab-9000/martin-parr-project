# Origin

Forked locally from the user's `kodachrome-film` source at commit
`ed1c1dc623d19a1caeefb05e1266e7a64f0443c8` on branch
`feature/show-graded-captures`.

Reuses the color math, normalization, LUT fitting, evaluation, artifact integrity,
image I/O, camera capture, fullscreen snapshot display, TV-bar loading screen and
tests. Historical algorithm comments and measured limits refer to that upstream
work. The Python package is now `parr`, the distribution is `martin-parr-project`,
and commands are `parr-*`.

The upstream fitted Kodachrome LUT, training images, artifacts, reports, reference
attribution and Git history were not imported. The bundled LUT is generated by
`parr.preset` and explicitly records `trained: false`. Grain is reduced for the
fine-grain target, and target normalization uses exposure matching by default
without stretching black and white points. The original project remains unchanged.

The project is an independent visual experiment, not an official Martin Parr
product. Photographer names describe the intended inspiration, not provenance
of the current bundled preset.
