# Reference sources

Checked 2026-09-06. This is a discovery guide. A small downloaded pilot corpus
is documented in [the first training run](training-pilot-2026-09-06.md).
The [expanded run](training-expanded-2026-09-06.md) records collection from the
five additional sources below, including download failures and exclusions.
Rankings below are editorial judgments for the requested saturated color-negative
look. Keep image author, series/date, page URL, licence or permission notes,
and local filename with every selected training reference.

## Selection

Use photographs credited to Martin Parr from primary portfolios and publishers.
Fan-submission Flickr groups are excluded at the user's request.

For the first fit, select coherent color images with strong color, clean
highlights and useful skin/neutral references. Omit monochrome, strong vintage
fades, installation photographs, photos of Parr by other photographers, and
unrelated subject-only matches. Split burst sequences and near-duplicates
together; the inherited trainer splits by image but does not yet group by scene.
Use files you have permission to use and retain their source and credit metadata.

## Additional primary sources

| Source | Why it helps this project |
|---|---|
| [Parr's own FAQ](https://martinparr.com/faq/) | First-person technical account of consumer film, ring flash and saturation. It names multiple films and formats; low ISO is a chosen target, not a universal description of his career. |
| [Benidorm — Magnum](https://www.magnumphotos.com/arts-culture/society-arts-culture/martin-parr-benidorm/) | High-priority visual reference: 1997 macro/ring-flash work and Common Sense examples. The page also contains later photographs, so curate by caption/date. |
| [Common Sense — Dewi Lewis](https://www.dewilewis.com/products/common-sense) | The publisher's description of the strongly colored 1999 book. A useful anchor for the most exaggerated color direction. |
| [Real Food — Phaidon](https://www.phaidon.com/en-us/products/real-food) | Publisher's collection of close-up food photographs across Parr's career. Good for color and highlights, but avoid letting a food-heavy corpus bias all camera scenes. |
| [The Last Resort — Martin Parr Foundation](https://martinparrfoundation.org/exhibitions/the-last-resort/) | Authoritative 1983–85 New Brighton reference; compare its color treatment separately from the later macro work. |
| [The Last Resort — Dewi Lewis](https://www.dewilewis.com/products/the-last-resort) | Publisher's context and consistent book edit, useful as a distinct alternative training target. |
| [Small World — Dewi Lewis](https://www.dewilewis.com/products/small-world-new-revised-edition) | Tourism reference with a broader range of scenes. The current edition mixes old and recent images; don't assume every photograph is film-era. |
| [Common Sense installation archive](https://martinparr.com/common-sense/) | Helpful for understanding the project and its presentation; installation views are not clean image files for color fitting. |

These are attributed references, not an openly licensed dataset. Training data
and generated models remain local and gitignored. Archived page HTML and
manifests distinguish successful downloads from discovered links.

My starting recommendation is the Benidorm/Common Sense direction, using
photographs credited to Parr. Keep The Last Resort and later fashion images as
separate comparison sets until a single coherent target is chosen. Fit color and
tone from those references; capture lighting and composition remain camera-side
decisions. Reference links alone do not establish that a model has been trained.
